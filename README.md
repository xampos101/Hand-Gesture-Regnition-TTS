# Hand Sign Recognition to Speech System

A real-time hand sign recognition system that converts hand gestures (A-Z letters) into speech using MediaPipe for hand tracking, TensorFlow Lite for inference, and text-to-speech for audio output.

## Project Structure

```
Hand Sign Recognition/
├── data_collector.py      # MediaPipe landmark extraction & CSV logging
├── train_model.py         # Model training & TFLite conversion
├── inference_app.py       # Real-time inference with threaded TTS
├── requirements.txt       # Python dependencies
├── README.md             # This file
├── dataset.csv           # Generated by data_collector.py
├── model.h5              # Generated by train_model.py
├── model.tflite          # Generated by train_model.py (optimized)
└── label_encoder.pkl     # Generated by train_model.py
```

## Features

- **42 Feature Hand Tracking**: Extracts 21 hand landmarks (x, y coordinates) normalized relative to the wrist
- **Real-time Inference**: Fast TFLite model for real-time gesture recognition
- **Text-to-Speech**: Threaded TTS system that speaks recognized hand signs
- **Debounce Logic**: Prevents repeated speech for the same gesture
- **Raspberry Pi Optimized**: Frame skipping and efficient processing for edge devices

## Usage

### Step 1: Data Collection

Collect hand sign data using the data collector:

```bash
python data_collector.py
```

**Instructions:**
- Position your hand in front of the webcam
- Press a letter key (A-Z) to label the current hand pose
- The script will log the normalized landmarks to `dataset.csv`
- Collect multiple samples (recommended: 50-100 per class) for better accuracy
- Press 'q' to quit

**Tips for data collection:**
- Collect samples from different angles and distances
- Vary lighting conditions if possible
- Hold each gesture steady for a moment when pressing the key
- Try to maintain consistent hand orientation

### Step 2: Model Training

Train the neural network model:

```bash
python train_model.py
```

This script will:
- Load data from `dataset.csv`
- Encode labels using LabelEncoder
- Split data into training (80%) and validation (20%) sets
- Train a neural network with dropout regularization
- Save the Keras model as `model.h5`
- Convert to TFLite format with quantization as `model.tflite`
- Save the label encoder as `label_encoder.pkl`
- Display training metrics and evaluation results

**Expected output:**
- Training progress and validation accuracy
- Classification report with per-class metrics
- Confusion matrix
- Saved model files

### Step 3: Real-time Inference

Run the inference application:

```bash
python inference_app.py
```

**Features:**
- Real-time hand tracking and gesture recognition
- Visual feedback showing predicted class and confidence
- Automatic text-to-speech output after debounce period (1.5 seconds)
- Press 'q' to quit

**How it works:**
1. The app captures frames from your webcam
2. MediaPipe extracts hand landmarks
3. Landmarks are normalized relative to the wrist
4. TFLite model predicts the gesture class
5. After holding a gesture for 1.5 seconds, TTS speaks the letter
6. Debounce prevents repeated speech for the same gesture

## Architecture Overview

```
Webcam Feed → MediaPipe Hands → Extract 21 Landmarks → Normalize to Wrist
    ↓
42 Features (x,y) → TFLite Model → Classification → Debounce Check
    ↓
If held > threshold → TTS Thread → Speech Output
```

### Model Architecture

- **Input**: 42 features (21 landmarks × 2 coordinates)
- **Architecture**: Dense layers: 128 → 64 → 32 → num_classes
- **Activation**: ReLU (hidden), Softmax (output)
- **Regularization**: Dropout (0.3-0.4)
- **Optimizer**: Adam
- **Loss**: Sparse Categorical Crossentropy

## Raspberry Pi Optimization Tips

For deployment on Raspberry Pi or similar edge devices:

### 1. Reduce Frame Processing Rate

In `inference_app.py`, adjust the frame skipping:
```python
if frame_skip % 3 != 0:  # Process every 3rd frame instead of every 2nd
    continue
```

### 2. Lower Camera Resolution

Modify video capture resolution:
```python
cap.set(cv2.CAP_PROP_FRAME_WIDTH, 320)
cap.set(cv2.CAP_PROP_FRAME_HEIGHT, 240)
```

### 3. Use TensorFlow Lite GPU Delegate (if available)

For Raspberry Pi with GPU support, enable GPU delegate:
```python
interpreter = tf.lite.Interpreter(
    model_path='model.tflite',
    experimental_delegates=[tf.lite.experimental.load_delegate('libedgetpu.so')]
)
```

### 4. Adjust MediaPipe Settings

Reduce MediaPipe complexity:
```python
hands = mp_hands.Hands(
    static_image_mode=False,
    max_num_hands=1,
    min_detection_confidence=0.7,  # Increase threshold
    min_tracking_confidence=0.7
)
```

### 5. System Optimizations

- Use a lightweight desktop environment
- Close unnecessary background processes
- Consider using a USB 3.0 webcam for better performance
- Increase GPU memory split if using GPU acceleration

## Troubleshooting

### Issue: Webcam not detected
- **Solution**: Check camera permissions and ensure no other application is using the webcam
- On Linux, you may need to add user to video group: `sudo usermod -a -G video $USER`

### Issue: Low accuracy during inference
- **Solution**: Collect more training data (aim for 100+ samples per class)
- Ensure consistent normalization during training and inference
- Check that lighting conditions are similar to training data

### Issue: TTS not working
- **Solution**: Install system TTS engine:
  - Windows: Built-in (should work out of the box)
  - Linux: `sudo apt-get install espeak` or `sudo apt-get install festival`
  - Mac: Built-in (should work out of the box)

### Issue: Performance issues on Raspberry Pi
- **Solution**: Apply optimization tips above
- Reduce frame processing rate further
- Use lower camera resolution
- Consider using a faster SD card (Class 10 or better)

### Issue: Model file not found
- **Solution**: Ensure you've run `train_model.py` first to generate `model.tflite` and `label_encoder.pkl`
